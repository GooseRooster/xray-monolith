## Gotchas / follow-ups
- **a983c54f** replays a mod's `pda.property_box_add_properties` callback
  a second time (into a scratch box) on every menu-item click, to rebuild
  per-spot state for multi-spot merged menus. If any gamedata mod's
  add-properties callback has side effects beyond adding list items
  (counters, RNG draws, telemetry), those would now fire twice per click.
  Upstream's own comment acknowledges this is a hack. Not a reason to
  skip - just worth a playtest with whatever mods/scripts hook
  `property_box_add_properties` in the active gamedata tree. → `bug_found`
  (speculative, not confirmed).
- **5d369a20** changes portrait rendering from stretch-to-fill to
  aspect-cropped "cover" for companion list icons, PDA contact icons,
  inventory portraits, news items, and ranking icons - a visible, if minor,
  UI look change. → `playtest`
- No `ordering_after`, `dangling_reference`, or `hotzone_gap` findings this
  session.
